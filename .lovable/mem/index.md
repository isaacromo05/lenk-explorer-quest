# Project Memory

## Core
Design system "Lenk Explorer Quest": Primary #1A2B4C, Secondary #2D5A27, Gold #D4AF37 (rewards only), bg #F8F9FA, surface #FFF, border #E2E8F0, text #0F172A.
Plus Jakarta Sans (Inter fallback). Cards rounded-2xl, buttons rounded-xl, badges rounded-full, shadows soft (sm/md).
Never use raw color/radius/shadow literals — always token utilities from src/design-system/styles/theme.css.
